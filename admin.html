Password help

The panel uses one administrator password, kept as a one-way hash inside the rate card. The factory password is mhs-admin — change it under Security as soon as you sign in.

Forgot it? Delete catalog.json next to serve.js (or clear this site's browser storage) and the factory password works again.

This sign-in keeps the numbers off the screen for casual users. It is not encryption — anyone who can read the files on this PC can read the rate card.

4 Administrator password

The password locks this panel and authorises every save sent to serve.js. Changing it also re-signs future publishes, so do it while you are signed in.

Use at least 8 characters. The password is stored only as a hash, never as text — write it down somewhere safe, because it cannot be recovered from the file.

5 Backup, import and activity log

Keep an export of the rate card before a price change — it is the only way back to an earlier set of rates.

Import replaces the whole rate card (tiers, models, settings and password hash). You still have to press Save changes afterwards.

How saving works

  • Save in this browser writes the rate card to this browser's storage. It works even when the calculator is opened by double-clicking the file.
  • Publish to the local server sends the same document to PUT /api/rates, which stores it in catalog.json in this folder. Everybody who opens the calculator from localhost then sees the new rates.
  • The calculator always prefers the newest copy (server and browser copies are compared by their timestamp).
  • Saving needs the network API, so keep node serve.js running. If publishing fails, the browser copy is still saved.
